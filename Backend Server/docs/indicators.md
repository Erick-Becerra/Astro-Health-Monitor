# Indicator rules (generated)

Generated by `scripts/export_indicators_doc.py` from `backend/shared/indicators.py`. Do not edit by hand.
The backend classifies each value as **Normal (green) / Caution (yellow) / Moderate risk (orange) / Critical (red)**;
the front only paints. Ranges are `low <= value < high`.

**Procedure (green):**
1. Continuous logging in the logbook.

**Procedure (yellow):**
1. Verify airflow is not blocked.
2. Check the status of the CO₂ scrubbers.
3. Ask the crew about headache or fatigue.
4. Reduce physical effort in the area.
5. Repeat the reading in 30 min.

**Procedure (orange):**

2. Activate or replace backup scrubbers.
3. Suspend intense exercise.

5. Monitor symptoms (headache, dizziness, shortness of breath) every 15 min.

**Procedure (red):**
1. Sound the alarm for the whole crew.
2. Isolate the affected module.
3. Use backup air supply / equipment.
4. Assess symptoms in each crew member.
5. Contact Mission Control.
6. Evaluate moving to a safe module or returning.

## Personal thresholds

These indicators take per-astronaut thresholds that replace the high bands:

- `heart_rate` (table `hr_rest`)
- `body_temperature` (table `temp_rest`)
- `blood_pressure_systolic` (table `bp_sys`)
- `blood_pressure_diastolic` (table `bp_dia`)
- `respiratory_rate` (table `resp`)
- `cabin_co2_mmhg` (table `co2`)
- `radiation_rate_msv_day` (table `rad_rate`)

## Other rules

- Activity state: heart rate and temperature use the at-rest, sleep or activity scale; the first 30 min after an exercise/EVA session use the activity scale.
- Sleep: nights in a row under 6 h (2 = Moderate risk) and under 4 h (3 = Critical).
- Reaction time (PVT) is judged against the astronaut's `baseline_pvt_ms` (default 300).
- Signal quality: degraded = Caution; lost < 5 min = Caution; lost >= 5 min on a vital sensor = Critical; lost on other variables = Moderate risk. Lost values are not evaluated.
- PHQ-9 / GAD-7 arrive in the packet as `mood_assessment`; PHQ-9 item 9 above 0 is always Critical with its own procedure.
- Communication link (latency / link down) has its own level and does not change the crew level.
